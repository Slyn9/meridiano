# Meridiano — documentación

Meridiano es la guía visual común de las aplicaciones de DN Systems. Esta carpeta contiene lo que vale para todas; lo propio de cada aplicación (su menú, sus formularios de negocio) vive en el repositorio de esa aplicación.

## Identidad

Meridiano tiene identidad propia: nombre, paleta (azul de DN Systems, matiz ≈228°), tipografía abierta (Inter e IBM Plex Mono) e íconos lucide. Su composición — superficies blancas sobre un fondo gris, menú lateral claro, pestañas subrayadas, estados con fondo tenue — es la de una interfaz empresarial moderna; no reproduce los valores, recursos, textos ni nombres de ningún producto de terceros, y ningún nombre de clase, componente o documento usa marcas ajenas.
